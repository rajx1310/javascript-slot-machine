# 🎰 JavaScript Slot Machine Game

A simple **command-line Slot Machine game** built with **JavaScript and Node.js**. This project is designed to practice JavaScript fundamentals such as functions, loops, objects, arrays, randomization, input validation, and game logic.

## 🚀 Features

* 💰 Deposit money before playing
* 🎯 Choose the number of betting lines
* 💵 Set a bet amount for each line
* 🎰 Randomly generate slot symbols
* 🏆 Calculate winnings based on matching symbols
* 📊 Track the player's balance after every spin
* 🔁 Play multiple rounds
* 🛡️ Validate user input

## 🛠️ Technologies Used

* JavaScript
* Node.js
* `prompt-sync`

## ⚙️ Installation & Setup


git clone https://github.com/rajx1310/javascript-slot-machine

cd javascript-slot-machine

npm install

node project.js


## 🎮 How to Play

1. Enter your initial deposit.
2. Choose the number of betting lines.
3. Enter your bet amount per line.
4. The slot machine generates random symbols.
5. Matching symbols generate winnings.
6. Your balance is updated automatically.
7. Choose whether to play another round.
